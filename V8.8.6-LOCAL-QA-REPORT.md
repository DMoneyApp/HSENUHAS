# NUHAS HSE360 V8.8.6 — Local QA report

## Focus
Certificate PDF text/OCR reliability after user feedback that a scanned award certificate populated a symbol-noise issuer and failed to identify likely award wording or dates.

## Results

- `node --check app.js` — PASS.
- `node qa/certificate-reader-smoke.js` — PASS, including date formats (`DD/MM/YYYY`, ISO, month names, hyphenated month names, ordinal suffix), PDF text layout grouping, award title/recipient extraction, issuer-noise rejection, OCR confidence bands and fallback heuristics.
- All 16 scripts under `qa/*.js` — PASS in the local Node runtime.
- SHA-256 manifest — every listed file verifies after packaging.
- ZIP integrity — PASS.

## Test boundaries

These checks exercise deterministic parsing/validation helpers and static source contracts. They do not run the actual Tesseract engine on the user's original PDF, a signed-in browser session, a live Supabase Storage upload, PostgreSQL migrations or cross-tenant authorization tests. The source PDF itself was not supplied; only a browser screenshot of the prior extraction result was available.

- Clear action resets visible query and in-memory search query.
- Escape/outside-click and record selection dismiss the mobile search appropriately.

## Limits

These are source-level regression checks; they do not execute a real browser DOM, touch input, screen-reader support, Supabase Auth/RPC, PostgreSQL RLS, Storage policies or production workflows. The UI permission filter is not a substitute for backend authorization. Search does not query server-side records that have not already been loaded. Do not mark the site production-ready until authenticated browser, staging security and business workflow tests pass.

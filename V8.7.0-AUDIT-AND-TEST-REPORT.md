## Changes in V8.7.0

- Added a PDF certificate/permit/NOC assistant in Import & Extract.
- PDF.js extracts selectable text; when text extraction is insufficient, Tesseract.js performs English OCR in the browser on up to 10 pages.
- Deterministic heuristics suggest document type, document/certificate number, issuer, issue date and expiry/valid-until date.
- Ambiguous numeric dates are left blank rather than guessed.
- The user must review/edit fields and explicitly save; the record is created in the active organization via the existing `create_hse_record` RPC in `licenses`.
- Saves extraction metadata and a limited extracted-text excerpt. The source PDF is not uploaded or retained.
- Added helper tests and a usage/limitation guide.
- No SQL migration added; the feature uses the existing licenses module and JSON record data.

## Security and data handling notes

OCR is performed in the browser. The app loads pinned JavaScript libraries and OCR model resources from public CDNs, so the browser needs network access. The certificate PDF is not sent to a hosted AI provider by this implementation. There is no learning/training or cross-company document memory. Suggestions are not proof of authenticity and must be verified against the source. The source PDF is not persisted; use the organization's approved secure document storage separately until an attachment workflow is implemented and tested.

## Deployment caution

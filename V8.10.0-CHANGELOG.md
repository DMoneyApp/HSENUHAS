# NUHAS HSE360 V8.10.0 — Field Continuity & Inspection Templates

Date: 12 October 2026
Type: cumulative local release candidate, built on V8.9.0.

## New implementation

- Added user- and company-scoped, session-only autosave/recovery for create/edit forms. Users can explicitly restore or discard an unfinished draft; the dashboard can list and resume drafts retained in the same browser tab session.
- Draft snapshots exclude file inputs. The UI states that unsent drafts are session-only, are not authoritative company records, do not sync between devices, and require attachments to be selected again.
- Added repeatable fire-equipment checklist starters: weekly extinguisher visual check, monthly detailed fire-equipment inspection, and monthly hose-reel/hydrant visual check.
- Checklist selection shows only applicable check items. New checklist items begin at “Select result”, never “OK”. Submitting a selected checklist requires an actual result for every applicable point and the overall inspection result. Any “NOT OK” result requires follow-up to be set and a corrective-action/remarks note recorded.
- Persisted template identity and applicable checklist points with the fire-equipment record and included the selected template title in print/PDF output.
- Applied JSA picker changes to the current-session draft snapshot so programmatically inserted hazards and controls are recoverable.
- Added two dedicated regression smoke scripts for session draft recovery and fire checklist safety validation.
- Added `PRODUCT-ADVANCEMENTS-10.md`, consolidating ten product patterns and the source URLs used to study them.
- Updated the cumulative release version, QA report, checkpoint and SHA-256 manifests.

## Ten product patterns included in the cumulative master

1. Fast mobile-first quick capture and progressive disclosure.
2. Recoverable in-tab form drafts (new in V8.10.0).
3. Weekly/monthly reusable inspection checklist starters (new in V8.10.0).
4. Searchable and company-saved JSA template reuse.
5. Permit/JSA linkage and Draft-first permit handling with safety-critical client validation.
6. Source-linked corrective actions, due dates, evidence and effectiveness verification UI.
7. Expiry/renewal monitoring and exportable renewal list.
8. Review-before-save document/spreadsheet import and certificate OCR suggestions.
9. Controlled report/print-to-PDF fields and CSV/JSON exports.
10. Notification read/dismiss controls, source navigation and navigation badges.

See `PRODUCT-ADVANCEMENTS-10.md` for vendor references, adoption decisions and known gaps. Some entries predate V8.10.0 and are preserved/integrated rather than newly authored in this release.

## Data and security considerations

- No SQL schema migration was added in V8.10.0.
- No live data, Supabase configuration, GitHub branch or deployed website was changed.
- Local browser drafts are a recovery convenience, not a multi-device/offline-sync implementation. Session storage is not encrypted; use on trusted devices only and end the tab session after handling sensitive records.
- Checklist templates are prompts. They do not verify equipment, certify compliance or approve a site-specific risk assessment.
- Existing backend authorization, RLS, Storage rules, permit database triggers and notification persistence still require staging/live verification.

## Release state

Local cumulative release candidate only. Static and deterministic smoke checks can pass while live authentication, tenant isolation, storage permissions, browser workflows and rendered print/PDF behavior remain unverified. Do not treat this release as production-ready until the release gates in `V8.10.0-LOCAL-QA-REPORT.md` are satisfied.

## Not proven by these checks

The tests are static/source regression checks. They do not execute a real browser DOM, Supabase Auth/RPC, PostgreSQL RLS, Storage policies or production business workflows. The UI permission filter is not a substitute for backend authorization. Do not mark the site production-ready until authenticated browser and staging security tests pass.

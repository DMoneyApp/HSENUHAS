# NUHAS HSE360 V8.10.2 — Mobile Global Search & Search Accuracy

Date: 13 October 2026  
Type: cumulative local release candidate based on V8.10.1.

## New implementation

- Added a dedicated search icon on narrow mobile layouts, where the desktop search input was previously hidden.
- Tapping the icon expands the search field, reports state with `aria-expanded`, updates the accessible label, and focuses the input; Escape restores focus to the toggle on mobile without stealing focus on desktop.
- Added a clear-search control that resets both input and in-memory query state.
- Escape closes the result list first and closes the mobile search when the result list is already closed.
- Clicking outside the mobile search dismisses it; selecting a result dismisses it before opening the record detail.
- Improved narrow-screen sizing and dynamic-viewport height for the result panel, including use of existing surface tokens for theme consistency.
- Corrected the no-match Enter behavior: it no longer sends users to the unrelated Observations module when the global query has no result.
- Added dedicated static regression tests for mobile access, dismissal, clear behavior, theme layout and no-match Enter handling.

## Safety and limits

- Search continues to use records already loaded in the active workspace and applies current module view checks in the client.
- This UI filter is not an authorization boundary; tenant isolation must be enforced by Supabase RLS and database permissions.
- Authenticated browser tests on real desktop/mobile sizes, live backend checks, GitHub reconciliation and deployment remain outstanding.
- No production SQL migration, GitHub push or live data mutation occurred.

# NUHAS HSE360 V8.8.5 — Compliance renewal reminder windows

## Implemented in the local cumulative master

- Replaced the two-calendar-month renewal horizon with an exact 90-day window using validated ISO calendar dates and UTC day arithmetic. All overdue items remain visible.
- Added explicit alert bands for **expired/overdue**, **expires today**, **within 7 days**, **within 30 days**, **within 60 days**, and **within 90 days**. The notification title changes at each threshold, making the next review stage visible.
- Fixed a logic defect where compliance records marked `Valid` or `Compliant` could suppress future alerts even when their expiry was approaching. Upcoming validity dates now generate reminders; explicitly `Renewed`, `Closed`, or `Not in use` records remain suppressed. Superseded certificate predecessors are also suppressed while their successor remains tracked.
- Nonblank malformed or impossible ISO expiry dates now surface as **Invalid expiry date** rather than silently disappearing from the renewal queue. The dashboard reports these records for correction. Empty expiry fields remain unalerted because not every licence/contract has an expiry requirement.
- Renewal notification text includes the record, owner/responsible person where available, expiry date, days remaining or days overdue. Missing owner is explicitly indicated.
- Dashboard renewal watch now shows overdue, due within 7 days, due 8–90 days, and invalid-date counts.
- Added `qa/compliance-renewal-reminders.js` for deterministic threshold/date tests and included it in the static smoke required-file list.

## Limits

- Notifications are generated when the application is active/open. This does **not** create a scheduled server-side background job, push notification, or email service.
- Renewal history and certificate duplicate indexes are local implementations/candidates; the V8.8.4 SQL migration has not been parsed or executed against PostgreSQL/Supabase.
- No live browser integration, authenticated storage validation, GitHub push or production database migration was performed.

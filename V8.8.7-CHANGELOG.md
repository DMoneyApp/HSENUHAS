# NUHAS HSE360 V8.8.7 — Actionable compliance renewal export

## Implemented
- Added an **Export renewal list** action to the dashboard's IMS Renewal Watch.
- Export uses the same `expiryItems()` source as the dashboard, preserving the active alert rules and suppressing superseded certificates.
- CSV includes module, record reference, document/employee name, certificate number, issuer/provider, responsible person, expiry date, days remaining, alert band, renewal status, successor reference(s), and record ID.
- All CSV values pass through the existing CSV-escaping helper to protect commas, quotes and line breaks.
- The file name includes the active workspace slug and export date.

## Why
The dashboard could show renewal counts but users needed an actionable list to share with department owners and use for follow-up. This is a manual export, not an email service or scheduled background reminder.

# NUHAS HSE360 V8.10.1 — Cross-Register Search & Field Continuity

Date: 13 October 2026  
Type: cumulative local release candidate based on V8.10.0.

## New implementation

- Replaced the global search bar's one-module-only Enter behavior with cross-register suggestions from records already loaded in the active workspace.
- Search matches reference, summary, location, department, creator, status, module and structured record data.
- Results are limited to eight recent matches and filtered through the user's module view permission before being displayed.
- Added accessible combobox/listbox/option semantics, keyboard navigation with Up/Down/Enter/Escape, outside-click dismissal, dark theme styles and small-screen result positioning.
- Selecting a result opens its record detail drawer; the search does not call a new backend endpoint or query another company.
- Added a dedicated deterministic source regression test for the search behavior.

## Validation

- `node --check app.js` passes.
- `qa/global-search-command-palette-smoke.js`: 10/10 checks pass.
- Full suite result is recorded in `V8.10.1-LOCAL-QA-REPORT.md`.
- Authenticated browser, real Supabase permissions, GitHub deployment and production workflows remain unverified.

## Known limits

- Search is limited to records already loaded into the active workspace. It is not server-side full-text search and cannot find records outside the currently loaded dataset.
- A source-level permission filter improves UI privacy but is not a security boundary; Supabase RLS and RPC permissions must enforce tenant and record access.
- The global search bar remains hidden at the narrowest mobile breakpoint in the existing responsive layout; a dedicated mobile search control is a separate follow-up.
- No GitHub push, production SQL migration or live data change occurred.

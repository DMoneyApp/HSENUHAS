# V8.11.1 — Release Notes (Development Candidate)

This development increment focuses on employee spreadsheet import reliability and safe duplicate review.

- Excel worksheet switching validates the retained workbook buffer and gives a recoverable error when it is missing.
- Common employee spreadsheet headings are mapped to the employee register fields.
- Joining date is optional; blank values remain blank.
- Name-only matches can be reviewed row-by-row. Employee code collisions are skipped to protect existing employee records.
- Import continues through the audited record-creation RPC; failed rows are reported without claiming transactional rollback.

**Status:** development branch only; not deployed or live-verified. Review the QA report and known issues before staging.

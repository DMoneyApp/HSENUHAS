# V8.11.1 — Organisation Document Control

Status: development branch; not deployed. The migration has not been applied to any database.

## Added
- New Document Master Register navigation entry.
- Organisation-scoped defaults for document prefix, controlled-document issue date, number format and default revision.
- Starter library of common HSE/IMS document types, including First Aid Register (FAR) and Fire Extinguisher Checklist (CHKL).
- Individual editable master rows for document name, document number, revision, issue date, effective-from date and active state.
- Bulk operation to set the current master issue date for all documents in the active organisation.
- Custom document entry and CSV export.
- Supabase schema with organisation RLS policies and history snapshots for master changes.
- Admin-only initialisation guard and corrected master-row active-checkbox selector.

## Not included yet
- Generic record forms still show their legacy per-record document-control fields.
- Printed forms do not yet resolve the correct effective document revision and save a per-record metadata snapshot.
- Dedicated history viewer and assigned reviewer/approver controls are not yet complete.
- The database migration and authenticated tenant tests have not been run in staging.

## Implemented in this package

- Source-record detail pages expose a permission-checked Create corrective action workflow for selected HSE registers.
- The workflow requires a specific action description, responsible person and due date; captures priority and effectiveness-check details.
- The new action stores `related_reference`, `source_record_id`, `source_module`, and `source_summary` in record data.
- Source records list linked corrective actions; users can open each linked action from the source detail view.
- Added responsive styling and a static regression guard.
- Preserved the V8.7 certificate PDF text extraction/OCR review workflow and V8.6.2 import retry fix.
- Added `HSE360-REAL-WORKFLOW-ROADMAP.md` prioritizing evidence-to-action, secure certificate retention/expiry management, permit lifecycle, mobile inspections, training competency, document control and authenticated tenant-isolation testing.

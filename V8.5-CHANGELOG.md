# HSE360 V8.5

## Included
- Reports & Analytics added to command-center navigation.
- Date-range report with register counts and selected records.
- Export selected-period records to CSV.
- Company-branded print layout with report/document number, revision, issue date and preparer metadata; use browser Print → Save as PDF.
- Reusable multi-select JSA starter library for common manufacturing/site activities. Templates insert activity, hazards and controls into the risk assessment form for review and site-specific editing.
- Fire Equipment Register now records inspection frequency and checklist period (weekly, monthly detailed, third-party/annual).
- Notification list now supports mark-read, mark-all-read and clear-list. Clear only hides notifications; it does not delete underlying HSE records.

## Safety / accuracy notes
- JSA templates are starting points, not approved site-specific risk assessments. Users must validate actual conditions, risk scores and controls.
- PDF output is generated through the browser print dialog; verify page breaks and content before formal issue.
- Notification state is browser-local and does not synchronize between devices.
- No Supabase schema migration is needed for this frontend-only addition.
- Syntax and static smoke tests only; live Supabase integration was not tested in this turn.

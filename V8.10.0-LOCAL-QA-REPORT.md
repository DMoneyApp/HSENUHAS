## Scope of these checks

The suite mostly validates JavaScript syntax, source markers and deterministic helpers. It does not execute Supabase auth/RPC calls, PostgreSQL migrations, RLS, Storage policies, or a complete authenticated browser workflow. The two V8.10.0 smoke scripts are regression guards over implementation source, not browser simulations.

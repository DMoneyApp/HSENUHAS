# V8.10.3 — Feature Completion & Limitations

| Workflow | Local implementation status | Important limitation |
|---|---|---|
| Role-specific training matrix | Implemented in frontend; CSV export; duplicate/scope/expiry review | Requires approved role-course definitions and accurate employee codes/certificates. No backend-enforced matrix rule. |
| Employee course evidence | Exact employee code + course code matching in matrix | Existing certificates may lack course codes; these will not match until data is reviewed and corrected. |
| Requirement validity | Uses explicit expiry or derives from issue date + configured refresh interval | No interval is inferred. Competent owner must approve the interval and issue/expiry data. |
| Audit findings to corrective actions | Missing linkage surfaced in audit review | A record-level warning is not an audit-plan engine and does not guarantee every individual finding has an action. |
| Major/critical incident/accident closure | Frontend requires actual linked corrective action for new closure | A direct API request can bypass UI logic unless an equivalent backend guard is verified; no Supabase change was made. |
| Waste movement traceability | Form + CSV import frontend preflight and review flags | Direct API calls may bypass front-end validation; verify server-side constraints separately at the final integration stage. Transport permit applicability still needs competent review. |
| Draft exception | Incomplete waste transfer may remain Draft | Draft is not a completed manifest/movement record or authorisation. |
| Existing application | Cumulative previous features and QA included | Browser-authenticated E2E, live Supabase, storage policy, cross-tenant security, actual PDF rendering and live deployment remain unverified. |

## Status interpretation
“Implemented” means implemented in this local codebase and covered by deterministic local checks, where noted. It does not mean deployed, approved as a legal process, or secured against direct API calls. Keep all operational safety decisions with authorized NUHAS personnel.

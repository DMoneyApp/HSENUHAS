# V8.11.0 — Integrated HSE Registers and One-Click Action Management

Date: 17 October 2026  
Status: Local cumulative development candidate; not deployed.

## Added

- Compact, record-backed operational tables for observations, near misses, incidents, accidents/LTI and first aid. Drafts are excluded from register rows; saved cancelled/void records remain visible.
- Inline Open / In Progress / Closed controls, focused remark and closure panels, locally defaulted effective date/time, retrospective reason, reopen reason, and linked action summaries.
- Reuse of the central canonical corrective-action records in source record details and register rows. Existing duplicate-summary protection remains active.
- A candidate Supabase trigger that appends authenticated history with the database timestamp, preserves prior history, keeps user-effective completion separate, validates close/reopen/backdate reasons, and prevents closing a case with active linked actions.
- Added operational workbook fields to the existing forms without removing the existing investigation, treatment, notification, witness, evidence or root-cause fields.

## Preserved

- V8.10.9 source changes and prior release documentation are included cumulatively. The prior V8.10.9 release ZIP, pre-change Git bundle and source snapshot were preserved as separate files and were not edited.
- Existing permit, attachment, CAPA, training, import/export, dashboard and tenant RPC flows remain in place.

## Main new feature

The certificate reader now uploads the reviewed source PDF to the existing private organization-scoped Supabase storage bucket and links the resulting metadata to the certificate record via `p_attachment`. Failure cleanup is attempted, with an explicit warning if it cannot be confirmed.

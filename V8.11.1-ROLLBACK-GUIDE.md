# V8.11.1 Rollback Guide

## Frontend
- Do not merge this branch into `main` until reviewed.
- If a preview has been configured, point the preview back to its prior branch/commit.
- Production GitHub Pages has not been changed by this work.

## Database
- The migration creates new document-control tables and policies; it does not alter existing HSE record tables.
- Prefer restoring the staging database from the pre-migration backup if tests fail.
- Do not drop the new tables in production as an automatic rollback: they may contain administrator-entered document metadata and history. Export those tables first and have the database owner approve any rollback SQL.
- No production database migration was applied during this development.
